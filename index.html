Try any number

The playground draws whatever you type, breaks it into base-10 digits, and lets you download SVG, PNG, JPEG or WebP.

Readable runs

Neighbouring 1s, 2s and 3s alternate upright and flat, the way Suzhou writers keep them apart. See how.

Zero dependencies

@suzhou-numerals/core turns a number into an SVG string in any JavaScript runtime.

Images and CLI

@suzhou-numerals/raster renders PNG, JPEG and WebP with sharp, and @suzhou-numerals/cli does it from the terminal.
