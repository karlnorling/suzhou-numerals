# Suzhou Numerals

Stories for [`@suzhou-numerals/core`](https://www.npmjs.com/package/@suzhou-numerals/core), which renders any number as [Suzhou numerals](https://en.wikipedia.org/wiki/Suzhou_numerals) in SVG.

- **Number Builder**: type any number in the `value` control and adjust every `toSvg` option.
- **Digits**: every digit from 0 to 9.

Zero is a circle, 1 to 3 are bars, 4 is a cross, and 5 to 9 put an upright bar on top of 0 to 4. Neighbouring 1s, 2s and 3s alternate upright and flat. A dot marks the decimal point, and negatives get a diagonal stroke.

For downloads and shareable links, use the [playground](../playground/) in the docs.
