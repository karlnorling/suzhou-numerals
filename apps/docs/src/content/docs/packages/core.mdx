## `toSvg(value, options?)`

Returns an SVG string. `value` can be a `number`, `bigint` or decimal `string`.

```js
import { toSvg } from '@suzhou-numerals/core';

toSvg(1993);
toSvg('3.14159', { size: 200, color: '#7a2e0e', background: 'white' });
```

| Option        | Default        | Notes                                                                                                   |
| ------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `size`        | `100`          | Image height in pixels. The width follows from the number of digits.                                    |
| `color`       | `currentColor` | Stroke colour. Takes a colour or a gradient.                                                            |
| `background`  | none           | Colour or gradient behind the numeral.                                                                  |
| `gap`         | `12`           | Space between digits, in viewBox units. A digit is 44 wide and 60 tall.                                 |
| `padding`     | `20`           | Space around the numeral, in viewBox units.                                                             |
| `strokeWidth` | `5`            | Stroke width in viewBox units, where a digit is 60 tall.                                                |
| `alternate`   | `true`         | Turns every second 1, 2 or 3 in a run on its side, so 21 is 〢一 rather than 〢〡, which reads like 〣. |
| `title`       | the number     | Accessible name. `false` leaves it out and sets `aria-hidden`.                                          |

Throws a `TypeError` for text that isn't a decimal number and a `RangeError` for `NaN`, `Infinity` or a bad option.

## Colours and gradients

`color` and `background` take any CSS colour, or a gradient: `linear-gradient()`, `radial-gradient()` and their `repeating-` forms. A gradient spans the whole image, so a long number runs through every colour once.

```js
toSvg('1234567', {
  color: 'linear-gradient(to right, #e03131, #f76707, #fab005, #40c057, #228be6, #7048e8, #be4bdb)',
});

toSvg('2026.1225', {
  color: 'repeating-linear-gradient(135deg, #e03131 0 3%, #ffffff 3% 6%)',
  background: 'radial-gradient(#2b8a3e, #0b3d20)',
});
```

Stops take percentage positions, and a stop with two positions (`red 0 3%`) makes a hard-edged band. Gradients can also be objects: `{ type: 'linear', angle: 90, stops: ['red', { color: 'blue', offset: 0.8 }] }`. `parseGradient(css)` turns a CSS gradient string into that form.

## Lower level

```js
import { BASE, digitSvg, format, parse } from '@suzhou-numerals/core';

parse(305); // { negative: false, integer: [3, 0, 5], fraction: [] }
flatDigits([2, 1]); // [false, true]: 21 is written 〢一
digitSvg(9); // an upright bar on top of a cross: 〩
BASE; // 10
```

- `parse(value)` → `{ negative, integer, fraction }`: the base-10 digits that get drawn, most significant first.
- `format(parsed)` → the canonical decimal string.
- `digitSvg(digit, place?, options?)` → one digit from 0 to 9 on its own. Digits are drawn upright; `place` makes no difference.
- `BASE` → `10`.
- `flatDigits(digits)` → which digits to turn flat under the alternating rule.
- `digitStrokes(digit, flat?)` → the lines and circles of one digit, for drawing somewhere else.
